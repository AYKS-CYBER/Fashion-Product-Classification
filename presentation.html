Slide 3 • Problem Definition

Project Motivation, Problem Statement & Objectives

⚠️ The Real-World Challenge
  • High-Volume E-Commerce: Major platforms (Amazon, Myntra, Flipkart) process millions of new product photos daily from third-party sellers.
  • Manual Cataloging Bottleneck: Manually reviewing, tagging, and filing each apparel photo into menus is labor-intensive, slow, and expensive.
  • Visual Ambiguity & Confusion: Subtle design overlaps (e.g., T-shirt vs Shirt vs Coat) cause human cataloging errors and inconsistent search tags.
  • Need for Automation: Demands millisecond-level, automated visual recognition to streamline catalogs and enable visual image search.
🎯 Key Project Objectives
  • Robust CNN Architecture: Design and train a deep Convolutional Neural Network capable of classifying 10 distinct fashion categories.
  • High Test Accuracy: Exceed 92% evaluation accuracy on 10,000 completely unseen benchmark test images.
  • Real-World Image Preprocessing: Solve domain shift issues (e.g., aspect-ratio squashing and background differences) when handling custom smartphone photos.
  • Interactive Web Deployment: Build and host a clean, responsive Streamlit web application providing instant predictions and probability breakdowns.
Slide 4 • Benchmark Dataset

Dataset Overview: Zalando's Fashion-MNIST Benchmark

📦 Dataset Scale & Characteristics
  • Benchmark Origin: Developed by Zalando Research as a more challenging modern drop-in replacement for classic MNIST handwritten digits.
  • 70,000 Total Images: Partitioned into 60,000 training examples and 10,000 unseen test examples.
  • Balanced Distribution: Exactly 7,000 images per class across 10 categories, eliminating class-imbalance bias.
  • Image Dimensions: 28 × 28 pixels, single-channel grayscale images with centered items.
  • Mathematical Normalization: Raw pixel integers [0, 255] scaled to [0.0, 1.0] for stable gradient descent.

Slide 5 • Deep Learning Architecture

Deep Convolutional Neural Network (CNN) Architecture

🧠 Why CNN over Traditional ANN?
  • Preserves 2D Spatial Geometry: An ANN flattens 28×28 into 784 numbers, losing 2D spatial relationships. CNNs scan adjacent pixels in 2D.
  • Weight Sharing: Slides identical 3×3 convolution kernels across the image, drastically cutting parameter count while avoiding overfitting.
  • Translation Invariance: Recognizes clothing items even if they are shifted or off-center.
  • Integrated Data Augmentation: Random horizontal flips, small translations, and zooms force the model to learn invariant clothing features.
⚙️ Enhanced VGG-Style Pipeline
  • Conv Block 1: Dual Conv2D(32, 3×3) + BatchNorm + MaxPool(2×2) + Dropout(0.20) → Captures edge & corner primitives.
  • Conv Block 2: Dual Conv2D(64, 3×3) + BatchNorm + MaxPool(2×2) + Dropout(0.25) → Learns mid-level outlines & shapes.
  • Conv Block 3: Dual Conv2D(128, 3×3) + BatchNorm + MaxPool(2×2) + Dropout(0.30) → Learns high-level category structures.
  • Dense Head: Flatten (6,272 units) → Dense(256) → Dense(128) → Dense(10, Softmax).
  • Optimizer: Adam with dynamic learning rate reduction (ReduceLROnPlateau).
Slide 6 • Preprocessing & Web App

Solving Real-World Image Challenges & Web Deployment

🔄 Smart Preprocessing Pipeline
  • The Challenge: Real smartphone photos have white backgrounds and 3:4 portrait ratios. Direct resizing squashes shirts into bulky coats!
  • Aspect-Ratio Letterboxing: Proportioned scaling (fits within 24×24) centered onto a 28×28 black canvas.
  • Smart Auto-Inversion: Evaluates corner pixel intensities. If background is light (>120), inverts it so objects are bright on dark.
  • Contrast & Noise Cleaning: Enhances button and collar contrast while zeroing out background shadow haze.
💻 Interactive Streamlit Interface
  • Zero-Latency Local Serving: Built with Streamlit and cached resource loaders (@st.cache_resource) for sub-25ms inference.
  • Multi-Format Image Upload: Supports drag-and-drop for JPG, JPEG, and PNG images.
  • Quick-Test Benchmark Library: Includes pre-loaded Fashion-MNIST test samples for immediate demonstration without files.
  • Visual Inspection: Side-by-side comparison of original image vs the 28×28 grayscale CNN input tensor.
  • Full Probability Distribution: Top-3 candidates with confidence scores and full 10-class interactive bar chart.
